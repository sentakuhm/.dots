# Quickshell community and references

## Official

- Quickshell 0.3.2 installation guide: https://quickshell.org/docs/v0.3.2/guide/install-setup/
- Quickshell 0.3.2 type reference: https://quickshell.org/docs/v0.3.2/types/
- Quickshell overview and recommended complete shells: https://quickshell.org/about/
- Hyprland Lua dispatchers: https://wiki.hypr.land/configuring/core/dispatchers/
- Hyprland `hyprctl` Lua evaluation: https://wiki.hypr.land/configuring/core/advanced-configuration/using-hyprctl/

## Community shells worth studying

- HyprQuick: https://github.com/x86kernel/HyprQuick — modular popups, weather/calendar and notifications.
- fbuedding/quickshell: https://github.com/fbuedding/quickshell — polished bar, PipeWire, MPRIS and DBusMenu tray patterns.
- doannc2212/quickshell-config: https://github.com/doannc2212/quickshell-config — modular bar, launcher, notifications, OSD and wallpaper manager.
- hyprbar: https://github.com/diogofd8/hyprbar — smaller top-bar design and clear notes for Hyprland Lua mode.
- quickshell-bar: https://github.com/MM-2103/quickshell-bar — broader desktop shell and control-center ideas.
- Caelestia: https://github.com/caelestia-dots/shell — full desktop shell reference.
- Illogical Impulse: https://github.com/end-4/dots-hyprland — another large, preconfigured Quickshell-based desktop setup.

Treat projects as design/API references, not drop-in modules. Check their required Quickshell version before copying code.
